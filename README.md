# Динамические структуры данных

Консольное приложение на C# / .NET 10. Собственные связные структуры используются в алгоритмах: стек, очередь, односвязный и кольцевой списки, бинарное дерево решений.

## Запуск

```powershell
dotnet run --project DynamicStructures
```

В главном меню раздел **4** содержит задачи 1–12 над списками, раздел **5** — применения структур. В разделе 5 пункт **4** разрешает файловые пути через `LinkedStack<string>`, пункт **5** запускает дерево решений для выбора транспорта.

## Задачи 9–12

При первом запуске задачи программа создаёт пример в `TestData/LinkedLists` рядом с исполняемым файлом и показывает полный путь. Enter выбирает этот файл; можно указать свой путь, в том числе в кавычках. Числа в строке разделяются пробелами или табуляцией; пустая строка означает пустой список. Допустимы целые числа от −2147483648 до 2147483647.

| Задача | Входной файл | Поведение |
| --- | --- | --- |
| 9 | `task9.txt`: две строки, первая — L, вторая — E | Дописывает независимую копию E к L, сохраняя E |
| 10 | `task10.txt`: одна строка | Разбивает после первого x; x остаётся в первом списке. Если x нет, первый список не меняется, второй пуст |
| 11 | `task11.txt`: одна строка | Дописывает копию исходного списка к нему самому |
| 12 | `task12.txt`: одна строка | Меняет два значения по позициям или первые вхождения двух заданных значений |

Пример `task9.txt`:

```text
1 2 3
4 5 6
```

В задаче 12 позиции в меню начинаются с **1**, в методе `SwapByPosition` — с **0**. При неверном вводе программа предлагает повторить ввод; отсутствующее значение или ошибка файла выводится сообщением. Список не меняется при ошибке перестановки. Для пустого второго списка в задаче 9 оставьте отдельную пустую строку после первой (файл `1 2 3\n\n`).

## Применения стека и дерева

Разрешение путей выполняется без обращения к файловой системе: обычная папка помещается в стек, `..` снимает её, `.` пропускается. Поддерживаются пути Windows (`C:\a\..\b` → `C:\b`), UNC (`\\server\share\a\..` → `\\server\share\`) и Unix (`/a/../b` → `/b`). Относительные пути остаются относительными, начальные `..` сохраняются. Выход выше абсолютного корня не допускается. Символические ссылки не разрешаются; пути вида `C:folder` и служебные пути Windows не поддерживаются.

Дерево решений хранит вопросы во внутренних узлах, а решения — в листьях. Программа показывает полное дерево и проходит выбранные ветви по ответам «да/нет» до результата. Принимаются также `д/н`, `yes/no`, `y/n`, `1/0`.

## Проверка

```powershell
dotnet build DynamicStructures.slnx
dotnet run --project DynamicStructures.Tests
```

Проверки запускаются отдельной консольной программой без сторонних тестовых пакетов. Они сравнивают алгоритмы со стандартными коллекциями и независимыми моделями, проверяют ошибки файлов и чисел, а также запускают приложение отдельными процессами и проходят его меню. При ошибке возвращается ненулевой код завершения.
